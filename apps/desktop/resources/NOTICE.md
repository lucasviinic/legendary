# Dados de terceiros

`lexicon/frequency.json` deriva de `content/2018/en/en_50k.txt` do projeto
[FrequencyWords](https://github.com/hermitdave/FrequencyWords), de Hermit Dave, gerado a partir do
corpus OpenSubtitles 2018. O conteúdo é distribuído sob a licença
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Foram mantidas as 30 mil primeiras
palavras em formato simples, sem as contagens.
